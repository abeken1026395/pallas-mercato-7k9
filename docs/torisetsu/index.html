3答え合わせの帯を読む

このサイトは毎朝、その日の全部のレースを3つに分けます。「荒れる」「混戦」「堅め」の3つです。

分け方は機械が決めます。管理人の予想ではありません。

そして夜、実際の結果と比べます。当たった割合をトップに出しています。

  1. いつ採点したか前の日の夜に採点しています。
  2. 前の日の結果その日の全レース数。
  3. 「荒れる」と見た本数と、実際に荒れた本数
  4. 「堅め」と見た本数と、実際に堅く決まった本数
  5. その日ぜんたい分けていないレースも入れた数です。見立てと比べられます。
  6. 通して見た結果始めてからの全部です。
  7. 2つの数字上が見立てたレース、下が全レース。上が下より大きければ、見立てが効いています。

3つの言葉の意味

  • 荒れる3連単の払戻が5,000円以上になること
  • 堅め3連単の払戻が5,000円より安いこと
  • 混戦どちらとも言っていないレース。答え合わせには入りません

おかしく見えるとき

こわれたように見えて、実は正しい表示です。

モーターの数字が全部 0.0% になっている
節の初日だからです。今節の成績がまだありません。数字が無いので、機力も判定に使いません。2日目から数字が入ります。
「機 −」とだけ出て、番号がない
そのとき、公式からモーターの番号が取れていません。1日に数回の取り込みで入ります。推測では入れません。
「N少」と書いてある
走った数が少なすぎる、という印です。1回走って1回2連対すると100％になってしまいます。だから注意書きを出します。
コース別の成績に「—」が出ている
そのコースを20回も走っていないからです。割合は出さず、走った数だけを出します。少ない数から率を作らない、という決まりです。
日数が「4+」のように「+」が付く
データのはしで節が切れています。本当はもっと長いです。数字は「これより少なくない」という意味で読んでください。
「枠」と「コース」の数字がちがう
枠は、くじで決まった艇の番号です。コースは、実際に走った位置です。前づけ（スタート前に内側へ動くこと）があると、2つはちがう数字になります。
見どころの「明日」が空、または少ない
明日のレースは、決まった場から順に増えます。夜になるほど数が増えます。
整備のページに今日の分が無い
直前情報は毎朝、前の日の分をまとめて取り込みます。載るのは前の日までです。
着の欄に「転覆」「F」「欠場」と出る
最後まで走れなかったレースです。妨害・エンスト・転覆・落水・沈没・不完走・失格・F・出遅・欠場を、そのまま出します。
