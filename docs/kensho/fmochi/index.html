F持ちのインは
遅れるのか

「F2だから、ここは行けない」と言われます。
3,587日・541,018回のスタートで確かめた記録です。

「①はF2ですからね。ここは行けないでしょう」

レース前の解説で、よく聞く一言です。行けない、行かない、慎重にならざるを得ない。言い方はいくつかあっても、どれも本人に確かめた話ではありません。

Fはフライング、合図より早くスタートラインを越えることです。切れば、その期のどこかでフライング休みに入り、2本目を切ると休みはさらに長くなる。だから攻められない、という理屈になります。

理屈は通っています。通っているので、数えました。

3,587日、541,018回

2016年11月1日から2026年8月27日まで、3,587日分の競走成績を1レースずつ見ていきました。1コースに入った舟を数えると、541,018回。同じ期間に、全部のコースで切られたFは12,753件。

F本数の数え方は、出走表と同じにしました。各期の初日、5月1日と11月1日に0へ戻し、そこからの累積を数える。出走表で見ている「F1」「F2」と、同じものを数えていることになります。

やはりそうか、と思った

F本数と級別で分けて、1コースのスタートタイミングを並べました。

並びはきれいで、A級のF2は0.1835秒と、B級のF0の0.1652秒より遅い。1着率も、A級のF0の66.3%から、F2では50.7%まで下がっていた。

これで話は終わった、と思いました。

別人を比べていた

ところが、これは見間違いです。

この図が比べているのは「F2の選手」と「F0の選手」で、別人どうし。A級のF2で1コースに入った1,671回を走ったのは、F2まで切ってしまう選手たちで、その人たちがもともとどんなスタートを踏むのかは、図からは分からない。

54万回を数えて、別人は別人だと確かめたことになります。

この段落は、うちが毎日集めている結果でも「F持ちのSTが遅い側にある」とき成立します。

時計しか持っていない

なぜ遅いのかを知るには、本人の胸の内が要ります。それは、データには入っていない。持っているのは、時計だけ。

そこで、比べる相手を変えました。同じ選手の、F0だったときと、F1やF2になったあとを引き算する。この形なら、その人がもともと速いか遅いかは、差し引かれて消えます。

F0 → F1+0.0158秒82.6%1,746人
F0 → F2+0.0430秒88.3%274人

F2まで進んだ選手の、10人に9人近くが遅くなっている。

たまたま遅い日が重なっただけ、ということはないのでしょうか。選手ごとに、1コースに入った日を単位にして、F0の日とF1の日のラベルだけを1,000回入れ替え、同じ計算をやり直しました。偶然なら、遅くなる人の割合は平均で49%、いちばん多い回でも53%で、実際の割合に届いた回は一度もありません。

この比べ方から外れた人もいる。F1で1コースに入った1,839人のうち、比べたのは1,746人で、F2は442人のうち274人。F0で10回、F1やF2で3回、1コースに入っていない選手は、1回か2回の走りで平均が決まってしまうので外しました。スタートが数字にならなかった3,595回、つまりフライングの3,548回と出遅れの47回も、平均には入れていません。外した走りのほとんどはF0の側にあり、F0を遅く見せる、差を縮める向きに効く。

級ひとつぶんの2倍

この遅れは、どれくらいの大きさなのか。物差しは、さきほどの図にあります。F0だけで見ると、A級とB級の平均STの差は0.0190秒で、級がひとつ違うと、それだけ変わる。

F2になった同じ選手の遅れは、その2倍を超えます。A級のF0の平均に足せば、B級のF0の平均を追い越してしまう大きさです。

出走表や結果に載るSTは、0.01秒刻みで記録されています。その目盛りで数えると、級ひとつぶんは2目盛りに届かず、F2の遅れは4目盛りと少し。A級のF0の平均はおよそコンマ15なので、そこに足すとコンマ19になる勘定です。

歳を取っただけでは

ここで、当然の疑いが出ます。

F0だったのが何年も前なら、年を取ったぶんだけ遅くなっていても不思議はない。それを「Fのせい」と読んでいるだけではないのか。

そこで、比べるF0を、Fを切る直前の2期、つまり半年から1年のあいだの走りに絞りました。遅くなった人の割合は、F1で82.6%から69.7%に落ち、F2は87.8%で、ほとんど動かない。F2の遅れだけは、時間を詰めても残る。はじめは、そう読みました。

引っかかったのは、F2の人数でした。比べられたのは181人で、この人数では、割合が5.6ポイントより小さく動いても、偶然と区別がつかない。ラベルを入れ替えた1,000回のうち、569回は実際より大きく動いている。F2が動かなかったことは、何の証拠にもなっていません。この記事の前の版は、その証拠にならないものを太字にしていました。

秒で並べ直すと、同じ選手どうしで、F1は0.0020秒、F2は0.0024秒縮んでいた。F2のほうはこの人数では見分けのつかない幅ですが、年齢のぶんが混ざっていたのは、F1に限った話ではなさそうです。それを抜いたあとも、F2の遅れは0.0412秒あり、偶然で届く幅の5倍を超えています。

級で割っても、年で割っても

向きは、級で割っても年で割っても同じ。A級でもB級でも、2016年から2025年のどの組でも、同じ選手はF1になると遅くなっています。

表の上ではF0

F持ちの話には、もうひとつ、よく聞く続きがあります。

「隠れF持ちは初日に負ける」

期が替わると、出走表のF表記は0に戻ります。けれどもフライング休みを、まだ消化していないことがある。表の上ではF0なのに、中身はF持ちという選手のことです。

これは、この記事の数え方の穴そのものでした。期の初日に0へ戻す数え方では、隠れFはF0の側に入る。では、F0のうち、どれくらいが隠れFだったのか。

前の期にFを切った選手のF0を「隠れF」として数えると、2017年5月からのF0の441,344回のうち、154,565回がそうでした。35.0%、3回に1回です。

比べたもの変化（秒）人数
隠れF − きれいなF0+0.00551,716
きれいなF0 → F1+0.01771,661
きれいなF0 → F2+0.0453269

同じ選手で比べると、隠れFのときのスタートは、きれいなF0のときより0.0055秒遅い。偶然で届く幅の5倍あまりで、F1になったときの遅れの、およそ3分の1にあたります。人をまたいで平均すると0.1540秒と0.1537秒でほぼ同じになり、ここでも別人どうしの平均が差を隠していました。

隠れFを基準から外して数え直すと、F0からF1への遅れはおよそ1割、F2は5%ほど広がりました。穴は、思っていたとおり差を縮める向きに開いていたことになる。数え方の穴を白状するつもりで数えたら、穴の中にも俗説が入っていました。

「初日に負ける」のほうは、節の何日目かを区別していないので、ここでは確かめていません。

切らない78人

もうひとつ、逆向きに見える数字が残っている。10年間で一度もFを切らず、F0で1コースに10回以上入った選手は78人いて、先に断っておくと、この78人には偏りがあります。最初に1コースに入ったとき、78人のうち69人がB級で、1コースに入った回数は中央値で73回と、切った側の237回の3分の1に届かない。そもそも1コースにあまり来ない人たち。

その78人の1コースの平均STは0.1897秒で、期間中にFを切ったことがある1,854人の、F0だったときの0.1595秒より遅い。Fを切る人は、切る前から速く踏んでいたことになります。

ただ、それが速く踏む人ほど越えてしまうからなのか、1コースに来ない人は切る機会も少ないだけなのかは、この78人では分けられません。

この段落は、うちが毎日集めている結果でも「Fを切ったことがある選手が、切る前から、切っていない選手より速く踏んでいる」とき成立します。
現在 切った側 0.1480 / 切っていない側 0.1564 ── ✓ 成立

ここから先は言えない

フライングの罰則は、2022年5月、2023年度、2025年と、3回改められました。4つの区間に分けて数え直すと、F0とF1の平均STの差は0.0095秒から0.0134秒の範囲に収まり、向きは変わっていません。

全員が遅くなるわけでもない。F2の状態で1コースに3回以上入り、その中に0.06秒より速いSTを含む選手が、50人いる。

時期が違えば、同じ選手の中で比べてもモーターも場も相手も変わるのに、そのぶんは揃えていません。

理由も書けません。遅くなった、という事実までがデータの届く範囲で、その人が何を考えて踏んだかは、時計には映らない。

この検証の数え方
  • 期間：2016年11月1日から2026年8月27日。公式の競走成績（Kファイル）の3,587日分で、欠けた日はありません。級別は同じ期間の番組表（Bファイル）から、その日の級別を引いています
  • 1コース：スタート展示ではなく、実際の進入で決めています。欠場を除いて541,018回
  • F本数：各期の初日（5月1日・11月1日）に0へ戻し、そこからの累積です。出走表のF表記と同じ定義です。F3以上は1コースで2回しかなく、F2にまとめています
  • スタートタイミング：本番のスタートだけで、スタート展示は含みません。数字にならなかった3,595回（フライング3,548回・出遅れ47回）は平均から外しています。1着率の分母は、着が1着から6着だった534,282回です（失格などの6,736回を除く）
  • 同じ選手での比較：F0で10回以上、比べる側（F1またはF2）で3回以上1コースに入った選手だけです。F1で1コースに入った1,839人のうち1,746人、F2は442人のうち274人
  • 直前2期：Fを切った日が属する期と、そのひとつ前の期。半年から1年のあいだの走りだけを基準にします
  • 偶然との比較：選手ごとに、1コースに入った日を単位に「F0の日」と「比べる側の日」のラベルだけを1,000回入れ替えています。理論上の確率分布は使っていません。乱数の種は20260922で、選手ごとに登番から種を作っています。見分けられる最小の差（偶然の揺れの2.8倍）は、全期間のF1で0.0013秒、F2で0.0055秒、直前2期のF1で0.0019秒、F2で0.0075秒です
  • 全期間と直前2期の違い：両方の比べ方に入る同じ選手（F1は1,188人、F2は181人）で、2つの値を選手ごとに入れ替えて1,000回数え直しています。遅くなった人の割合で見分けられる最小の差は、F1で4.1 ポイント、F2で5.6 ポイントでした
  • 級別に割った比較：初めてその本数で1コースに入った日の級別で分けています。A級とB級の差は、選手の間で級のラベルだけを1,000回入れ替えて比べました
  • 年ごとの比較：初めてF1で1コースに入った年で選手を分けています。2026年の19人は、見分けられる最小の差（0.0251秒）に実際の差が届かないため、値を出していません
  • 隠れF：前の期にFを1本以上切った選手の、次の期のF0の走りです。フライング休みをいつ消化したかはデータに無いため、その期のあいだはずっと隠れFとして数えています（消化したあとの走りも含む）。最初の期（2016年11月から2017年4月）は前の期が無いので、判定からも基準からも外しました。この期だけを外して隠れFを基準に残した場合、同じ選手の遅れはF1で0.0160秒、F2で0.0431秒で、隠れFも外すと本文の表の値になります
  • 切っていない選手：期間中に一度もFを切らず、F0で1コースに10回以上入った78人です。切った1,854人との差は、選手を単位にラベルを1,000回入れ替えた比較で、見分けられる最小の差（0.0073秒）を超えています
  • 罰則の区切り：2022年5月1日、2023年4月1日、2025年5月1日で4つに分けています。区間ごとの差は、同じ選手ではなく、区間の中のF0とF1の平均の差です
  • 揃えていないもの：同じ選手の中でも、時期が違えばモーター・場・相手が変わります。開催の格も揃えていません
