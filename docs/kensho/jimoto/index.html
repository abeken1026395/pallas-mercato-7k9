検 証

地元は
強いのか

地元の選手が1号艇に座っているのは、強いからなのか。
約10年分の番組表と成績を突き合わせて数えた記録です。

1号艇に座っている

大村の1号艇に、長崎の選手が座っている。津の1号艇には、三重の選手。節の初日の番組表を眺めていると、そういう並びをよく見かけます。

地元だからね。

たいていの説明は、そこで終わります。

数えました

2016年11月1日から2026年8月11日まで、3,571日ぶんの成績を数えました。538,270レース、延べ3,223,681走。選手の支部は、その日の番組表に印字されたものを使い、移籍した選手については、移籍の前と後を別に数えています。

支部と開催場の所在地が一致する走は709,667走で、全体の22.0%。5走に1走よりやや多い、という程度の割合です。

やはり強い

1着率を出すと、こうなりました。

延べ走1着率3着内率平均着
地元709,66718.1%51.6%3.44
地元以外2,514,01416.3%49.7%3.52

1着率で1.80ポイント、3着内率で1.99ポイント、平均着で0.08の差。分母がこれだけあるので、区間はほとんど重なりません。

俗説は当たっていた。ここで終われば、短い記事になります。

枠をもらっているだけではないか

ただ、冒頭の並びを思い出すと、順番が怪しくなります。地元の選手が1号艇に座っているのは、強いからでしょうか。それとも、座らせてもらったから強く見えるだけでしょうか。

数えました。地元の選手が1コースに入ったのは126,414回。同じレースの中で地元かどうかのラベルだけを1,000回入れ替えて作った帰無の平均が118,488回なので、7,926回ぶん多い。

入った・偶然なら

あっせんと番組の組み方は、地元の選手を内側に置いています。疑いは、当たっていました。

引いても残る

そこで、この差の中身を分けました。

1着率への寄与
進入コースの偏り+0.61pt
年齢の偏り+0.10pt
場の違い−0.01pt
出走数の偏り−0.03pt
級別の偏り−0.17pt
残り+1.30pt

いちばん大きいのは、やはり進入コース。けれども、それを引いても残りは消えませんでした。

同じ選手の中で比べても消えません。地元と地元以外の両方に20走以上ある2,024単位を取り、選手ごとに差を出すと、中央値は1.48ポイント。進入コースを揃えると0.84ポイントまで落ちますが、1,270単位が正、753単位が負で、正のほうが多いままでした。

冒頭の並びで見えているのは「地元が内枠で来る」という場面、こちらが見ているのは、内枠を揃えた後に残る分。見ている範囲が違うだけで、どちらも間違っていません。

では、近さか

残った分が水面の慣れなら、近い場も少しは慣れているはずでしょう。徳島の選手が丸亀を走り、福岡の選手が唐津を走る。同じ地区の、隣の県。地元ほどではないにしても、遠くから来た選手よりは走れるのではないか。

そう思って、3つに分けました。

延べ走1着率
地元709,66718.1%
近接（同じ地区の別支部）472,80815.7%
遠隔（別の地区）2,041,20616.4%

地元でも遠隔でもない真ん中が、3つのうちで、いちばん低い。隣の県から来た選手のほうが、遠くの県から来た選手より弱いことになります。

地図をしばらく眺めました。

級別を見た

近い場の走と遠い場の走で、級別の構成を比べます。

近接472,808走のうちB2は8.61%、遠隔2,041,206走のうちB2は4.82%。倍近く多い。A級は同じ分母で、近接が45.98%、遠隔が50.61%。4.63ポイント少ない。近い場に多く呼ばれているのは、下の級の選手。

なぜそうなるのかは分かりません。あっせんの決め方はデータに入っていないので、ここは確かめようがない。

消えました

級別と進入コースを揃えて、もう一度当てます。何ポイント残ったと思いますか。

統制前統制後
地元 − 遠隔+1.67pt+1.32pt
近接 − 遠隔−0.74pt+0.10pt

近接の差は、消えた。3着内率で残ったのは −0.0004ポイントで、これは差が無いと書くのが正直なところ。

同じ選手の中でも確かめました。近い場と遠い場の両方に20走以上ある1,995単位で、進入コースを揃えて比べると、正が992、負が1,001、中央値は −0.02ポイント。ほぼ半々になる。

消えた0.74ポイントの内訳は、級別と進入コースがそれぞれ0.39ポイント。ちょうど半分ずつでした。できすぎに見えたので年ごとにも当て直しましたが、統制後の符号が揃ったのは11年のうち7年。もともと向きが定まっていない、ということです。

ひとつ、揃えすぎの心配があります。級別は過去の成績の結果でもあるので、近い場ばかり走って成績を落とした分まで、一緒に消してしまったかもしれない。ただ、同じ選手の中では級別はほとんど動きません。その土俵でも半々だったので、揃えすぎが理由ではない。

いっぽう地元の係数は、3つの指標とも残りました。

地元の弱い版ではなかった

慣れが距離に応じて効いているなら、近接は、地元と遠隔の間に来るはずでした。実際には、統制すると、遠隔と同じ高さに並ぶ。

近い場を走る選手は、地元の選手を薄めた存在ではない。地元でないという一点において、別の地区から来た選手とまったく同じでした。

効かない場もある

場ごとにも出しました。地元が最も効くのは津で、シャッフルとの差は4.98ポイント。以下、びわこ、鳴門、尼崎と続く。

逆に、平和島は −0.66ポイント、多摩川は −0.68ポイントで、この2場では地元のほうがわずかに悪い。ただし24場ぶんをまとめて検定しているため、補正の取り方で判定が変わります。平和島はどちらの補正でも残り、多摩川は片方で残って片方で落ちた。

この2場を含む東京支部の3場は、384,499走のうち108,632走が地元。江戸川が124,193走で29.4%、平和島が127,424走で28.9%、多摩川が132,882走で26.6%と、どの場も全体の平均を上回ります。地元の選手が多い場ほど、地元であることが特別でなくなる、という形にも見えます。見えるだけで、確かめてはいません。

数えられなかったもの

番組表にあって成績に無い走が40,404走あります。9場が同じ日にまとめて欠けていたり、節の終わりのほうのレースだけ無かったり。開催が取りやめになった分と読めますが、確かめてはいません。これを全部地元と置いても、全部地元以外と置いても、最初の差は1.73ポイントまでしか動きません。

出身地はデータにない。支部と出身地が違う選手は、この集計では地元になったり、ならなかったりします。

なぜ地元が強いのかも、分かっていない。水面の慣れか、移動の負担か、応援か、あるいは別の何かか。集計をいくつ重ねても、そこには届きませんでした。

締め

地元は強い。枠とメンバーを揃えても、1.30ポイント残ります。

ただし、その強さは近さではありませんでした。地元の一歩外に出た時点で、効果は0です。

大村の1号艇の長崎の選手は、確かに少し強い。同じレースにいる佐賀の選手は、東京の選手と変わらない。

  • 地区：公式サイトが24場を6地区に分けている区分を、開催場の所在地支部を通じて支部に読み替えたものです。支部を地区に分ける公式の表は見つかりませんでした
