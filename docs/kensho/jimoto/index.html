検 証

地元は
強いのか

地元の選手が1号艇に座っているのは、強いからなのか。
約10年分の出走表と成績を突き合わせて数えた記録です。

1号艇に座っている

大村の1号艇に、長崎の選手が座っている。津の1号艇には、三重の選手。節の初日の出走表を眺めていると、そういう並びをよく見かけます。

「地元だからね」

その一言で、たいていの説明は終わります。そして終わったあとには、なんとなく、印がひとつ増えている。

数えました

では、その印にどれだけの根拠があるのか。2016年11月1日から2026年8月11日まで、3,571日分の成績を、一日ずつ数えました。538,270レース、延べ3,223,681走です。

地元かどうかは、その日の出走表に刷られた支部で決めています。出走表には選手ごとに支部が印字されていて、移籍すれば翌節からその欄が変わります。原田幸哉選手の欄は、2016年には愛知、いまは長崎。そのときどきの支部で数えるので、移籍の前と後は混ざらない。

支部と開催場の所在地が一致する走は709,667走。全体の22.0%で、5走に1走より少し多いくらいでした。

やはり強い

結果から書きます。

延べ走1着率3着内率平均着
地元709,66718.1%51.6%3.44
地元以外2,514,01416.3%49.7%3.52

1着率で1.80ポイント、3着内率で1.99ポイント、平均着では0.08の差。分母がこれだけあれば、区間はほとんど重なりません。やはり、俗説は当たっていました。

ただ、当たっていたからといって、話が終わるわけではありません。6艇のうちの1.8ポイントというのは、印をひとつ足す理由になる大きさでしょうか？　この数字のままでは、手が動かない。

枠をもらってるだけか？

しかも、順番が怪しいのです。

「あれは地元枠でもらったインでしょ」

そう言う人もいます。もういちど、冒頭の並びを思い出してください。地元の選手は、1号艇に座っていました。強いから座っているのか、それとも座らせてもらったから強く見えるだけなのか。

数えると、地元の選手が1コースに入ったのは126,414回。同じレースの中で地元のラベルだけを1,000回入れ替えて作った帰無の平均が118,488回ですから、7,926回ぶん多いことになります。

斡旋と番組の組み方が、地元の選手を内側に置いている。座らせてもらっているのは、本当でした。疑ったほうが当たっても、あまり嬉しくはありません。では、それだけなのか。

引いても残る

では、内枠の分を引いたら何も残らないのでしょうか。分けてみます。

1着率への寄与
進入コースの偏り+0.61pt
年齢の偏り+0.10pt
場の違い−0.01pt
出走数の偏り−0.03pt
級別の偏り−0.17pt
残り+1.30pt

いちばん大きいのは、やはり進入コースでした。それでも、引いたあとに1.30ポイントが残ります。

選手の顔ぶれで説明がつくのかとも思い、同じ選手の中でも比べました。地元と地元以外の両方に20走以上ある2,024単位を取り、ひとりずつ差を出すと、中央値は1.48ポイント。進入コースを揃えると0.84ポイントまで落ちますが、それでも1,270単位が正、753単位が負です。

ここで消えてくれれば、短い記事で済みました。枠でもなければ、顔ぶれでもない。地元というだけで、いくらか強い。

どこで効いてるか？

ただ、ここまでの数字は、全部の枠と全部の級を混ぜたものです。

「地元は買っとけ」

この形で使うには、混ぜたままでは、足りません。出走表の前に立ったとき、そこにいるのは平均ではなく、一人の選手です。

そこで、進入コースを6つ、級別を4つに切った24通りで比べ直しました。まずは、いちばん舟券の売れる1コースから。

1コースの選手延べ走（地元／地元以外）地元の1着率地元以外の1着率差
A141,931 / 137,87171.9%69.8%+2.14pt
A231,970 / 117,09760.3%58.2%+2.10pt
B148,584 / 148,59643.6%37.4%+6.26pt

A1とA2は、2ポイントほどしか変わらない。ところがB1だけ、6.26ポイント違います。

伸びるのは強い選手ではない

24通りのうち、差がいちばん大きいのが、このB1の1コースでした。混ぜて出した1.8ポイントの、3倍以上あります。

「やっぱり意地が違う」という説明もあります。意地が理由なら、A1の1号艇でも同じだけ上がってよさそうなものです。ところが、上がりませんでした。

考えてみれば、そうなるはずでした。A1の選手が1号艇に座れば、地元だろうと遠征だろうと7割は逃げ切ります。伸びる余地が、もう残っていない。いっぽうB1の1号艇は4割を切っていて、逃げるか差されるかが毎回わかれている。そのわかれ目に、地元が効いている。

反対に、いちばん差の小さいところも見ました。6コースのB2は、地元30,058走で0.60%、地元以外67,677走で0.59%。小数第2位で、どうにか地元が勝ちます。ここでは、地元であることに意味がない。

同じ「地元」という言葉が、4割逃げる舟と、めったに来ない舟の両方に付いている。出走表の支部欄は、どちらにも同じ二文字を刷っているだけだ。

近さで効いてるか？

もし地元が効く理由が水面の慣れなら、近い場でも、少しは効いていいはずだ。

2026年8月1日、唐津の1Rを見ます。佐賀支部の選手は、6人のうち1人もいませんでした。福岡支部の安武一也選手が、同じ九州から来ている。残る5人は、香川の小野寺智洋選手、東京の金山立樹選手、岡山の泉啓文選手、そして山口の小林孝弘選手と松田憲幸選手。どれも地区が違う。

この安武選手の走りが、地元と遠征の中間にあたります。

延べ走1着率
地元709,66718.1%
近接（同じ地区の別支部）472,80815.7%
遠隔（別の地区）2,041,20616.4%

真ん中が、いちばん低い。地図をしばらく眺めました。徳島と香川の位置は、何度見ても変わりません。慣れが距離で薄まるなら、近接は地元と遠隔の間に来るはずです。

種は級別でした。近接472,808走のうちB2は8.61%、遠隔2,041,206走では4.82%で、近い場には、下の級の選手が多く呼ばれている。級別と進入コースを揃えると、近接と遠隔の差は −0.74ポイントから +0.10ポイントになり、消えました。

隣の県は、地元の薄い版ではない。地元でないという一点において、別の地区から来た選手と同じでした。

効かない場はあるか？

場ごとにも出しました。地元が最も効くのは津で、シャッフルとの差は4.98ポイント。以下、びわこ、鳴門、尼崎と続く。

いっぽう平和島は −0.66ポイント、多摩川は −0.68ポイントで、この2場では地元のほうがわずかに悪い。ただし24場をまとめて検定しているので、補正の取り方で判定が変わります。平和島はどちらの補正でも残り、多摩川は片方で残って片方で落ちました。

この2場を含む東京支部の3場は、384,499走のうち108,632走が地元です。江戸川が124,193走で29.4%、平和島が127,424走で28.9%、多摩川が132,882走で26.6%と、どの場も全体の平均を上回ります。地元の選手が多い場ほど、地元であることが特別でなくなる。そう見えますが、確かめてはいません。

数えられなかったもの

「人気になるぶん、妙味はない」とも言われます。そのとおりかもしれません。

オッズは数えていません。地元が強いことと、地元の舟券が儲かることは、別の話です。強さが売れ方に織り込まれていれば、印をひとつ足したぶんは戻ってこない。ここで出したのは着順だけ。払戻については何も言えない。

出走表にあって成績に無い走が、40,404走あります。9場が同じ日にまとめて欠けていたり、節の終わりのレースだけ無かったり。取りやめになった分と読めますが、確かめてはいません。この40,404走を全部地元と置いても、全部地元以外と置いても、最初の差が動く先は1.73ポイントまでです。

1コースのB2は、地元3,929走と地元以外8,292走しかありません。2ポイントを見分けるには足りない。数字は出ていますが、大小は書きませんでした。

出身地はデータにありません。なぜ地元が強いのかも、分かっていない。水面の慣れか、移動の負担か、応援か。集計をいくつ重ねても、そこには届きませんでした。

締め

地元は強い。「地元だからね」は、当たっています。ただし、全部の舟が等しく強くなるわけではありません。

伸びるのは強い選手ではなく、決め手を欠く選手です。A1の1号艇に足す印は2ポイント分、B1の1号艇なら6ポイント分。同じ「地元」でも、値段が3倍違う。

大村の1号艇に長崎の選手を見つけたとき、次に目を落とすのは支部ではありません。同じ行の少し右に、小さく刷ってある級別のほうです。

  • 地元の定義：選手の支部が、開催場の所在地支部と一致すること。出身地は使っていません
  • 当地勝率とは別のものです。当地勝率はその場での成績なので、遠征してきた選手にも付きます。ここで数えたのは、支部と場が一致するかどうかだけです
  • 支部：その日の番組表に印字された値。移籍した選手は前後で別単位として数えました
  • 進入コース：スタート展示ではなく、実際の進入です
  • 比較の基準：同じレースの中で地元・近接・遠隔のラベルだけを1,000回入れ替えて作った分布と比べています。理論上の確率分布は使っていません
  • 統制：場・級別・進入コース・年齢帯・出走数帯
  • 区間：率はWilson、平均着は平均±1.96標準誤差
  • 24通りの比較：1コースのB2だけ、1着率で2ポイントの差を見分けるのに必要な延べ走数に届きません。残る23通りは、すべて地元のほうが上でした
  • 地区：公式サイトが24場を6地区に分けている区分を、開催場の所在地支部を通じて支部に読み替えたものです。支部を地区に分ける公式の表は見つかりませんでした
