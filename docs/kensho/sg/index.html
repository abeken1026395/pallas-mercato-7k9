検証 12

SGの勝率最下位は、
一般戦の勝率トップより上

SGで1号艇がインから勝ったレース。相手5人のうち、全国勝率が一番低い選手の勝率は、平均6.67です。一般戦で一番高い選手は6.30。SGのビリは、一般戦のトップより上にいます。

SGの着順点は2点ずつ多く付くので、同じ目盛りではありません。それでも、2着は読めなくなります。勝率が一番低い相手が2着に来るのは、一般戦なら13回に1回。SGでは6回に1回です。

「実力差の少ないSG」は、ボートレースの常識です。常識なら、数えれば裏が取れるはず。そう軽く考えたのが運の尽きで、20年分・111万3,940レースを数えることになりました。はっきり言えたのは、2着の話です。

この記事で使う言葉
SG・一般戦
SGは一番格の高い開催、一般戦は格の付かない普段の開催です（女子戦・新人戦・G2・G3などは除きます）

偶然の範囲
たまたまでも出る程度の差。開催日を選び直して何度も数え直し、その揺れの幅の2.8倍より小さい差をこう呼びます

勝率で並べると、
SGの2着は横一線

相手5人を全国勝率で並べて、2着に来た割合を数えました（この10年）。

勝率が一番高い34.6%24.5%

一般戦なら、勝率トップとビリで4倍以上の開きがあります。SGでは1.5倍。5人がまったく同じ力なら、誰でも5回に1回ですから、SGの2着欄は、そこにかなり近い。3着も同じ形で、SGでは22.1%と18.8%でした（SG3,397レース）。

元選手と記者は、
そもそも勝率でヒモを選ばない

競艇専門紙出身のコラムニストは、SG出場者は「実力差は外から考えるほど差はありません」として、「SG、GIは機力、一般戦は選手」と書いています。元ボートレーサーの解説者は、2着と3着を読むなら、1号艇がどう逃げる選手か、2号艇から後ろの仕上がり、その節のスタートを見る、と話していました。

元選手や専門誌の編集長が語る番組を7本、文字に起こして読みました。ヒモを全国勝率で選べと言った人は、1人もいませんでした。

そこで、相手5人を展示タイムの速い順と、モーター2連率の高い順にも並べました。

一般戦では、勝率がほかの2つを大きく引き離します。勝率トップとビリの2着率の差が26.7ポイント、展示タイムは10.8ポイント、モーター2連率は3.7ポイント。SGになると、勝率が7.9ポイントまで落ちて、展示タイム10.0ポイント、モーター5.8ポイントと横に並びます。SGでは、この3つの差どうしの開きが、どれも偶然の範囲です。

ただし、元選手が見る「足」は、周回展示の回り足や出足です。モーター2連率は前に使った選手たちの成績で、展示タイムは主に伸びの目安。数字に出にくい所を、彼らは見ています。

数えている途中、私は一度、展示タイムが勝率の2倍効くと思い込みました。展示タイムは0.01秒刻みで、半分ほどのレースに同じタイムの相手がいます。それを全部「1番手」に数えていたのです。順番を等分して数え直すと、SGの展示タイムの差は15.3ポイントから10.0ポイントに減りました。

もう1つ疑ったのは、コースです。SGでは勝率の高い相手が外のコースに回っていて、それで2着に来ないだけではないか。そこで、相手がいたコースごとに分けて数え直しました。

2コースにいた相手で比べると、勝率トップの2着率は一般戦49.8%、ビリは20.0%。SGでは40.6%と28.9%です。

2コースから6コースまでの差を平均すると、一般戦22.1ポイント、SG7.4ポイント。コースを揃えても、SGで勝率が2着を分ける力は一般戦の3分の1で、この差は偶然の範囲の外でした。その前の10年も23.7ポイントと8.1ポイントで、同じ形です。

相手が揃えば、
一般戦も同じ形になる

SGで勝率が効かないのは、SGだからなのか。一般戦を、相手5人の勝率の幅で分けてみました（記事を書く途中で足した数え方です）。

幅が3.0以上あるレースでは、勝率トップが2着に来るのが39.9%、ビリは3.2%。幅が1.0未満になると、25.1%と15.7%まで寄ります（1万1,513レース）。SGの24.5%と16.7%と、ほとんど同じ並びです。

幅が1.0未満のレースは、一般戦では5%ほどしかありません。SGでは4割を超えます。一般戦を、SGと同じ幅の割合に並べ直しました。勝率トップとビリの差は、26.7ポイントから13.3ポイントに下がります。SGの7.9ポイントとの開きは、これで7割が消えます。

SGで2着が読めない理由の大半は、SGの看板ではなく、相手5人の勝率の近さでした。残りの3割は、まだ理由が分かりません。予選の得点の取り方や、SGの選手の全国勝率の目盛りのずれが候補です。3連単の配当の上乗せも、相手の揃い方まで揃えて比べられた999レースでは17%から3%に縮みました。ただし、相手が一番揃ったSGはこの999レースから外れています（折りたたみ）。

最初に付けた題は「SGの1号艇は本当に強いのか」でした。いま読むと、ずいぶん素朴な問いです。1号艇しか見ていなかった。

次のSGの出走表では、まず相手5人の勝率の一番上から一番下を引き算します。1点に届かなければ、勝率の順に2着を絞るのはやめます。代わりに何で絞れるのかは、まだ数えていません。次に数えるのは、節の成績です。

インが強いかどうかは、20年分を数えても決めきれませんでした（折りたたみ）。

インの強さの数字

見たままなら、インは強い。この10年、イン1着率は一般戦54.1%、SG62.1%です（6,114レース）。ただ、SGの1号艇にはそもそも強い選手が乗っています。

選手の強さだけを揃えた比べ方では、SGのインは、この10年が100レースあたり5.7本少なく（4,746レース）、前の10年が3.5本少ない（4,506レース）。どちらも偶然の範囲の外です。

相手5人の平均勝率まで揃えられたのは、この10年の4分の1、1,153レースだけでした。同じ1,153レースで数えると、選手の強さだけで揃えた差は5.1本、相手まで揃えると2.5本で、偶然と見分けがつきません。インが強いかどうかは、この記事では結論を出しません。

少なさがはっきり言えるのは予選などのレースで、この10年は6.7本、前の10年は4.1本少なく、比べられたレースの9割近くがここに入ります。優勝戦は、比べられたのがこの10年で65レースしかなく、強いとも弱いとも言えません。

相手まで揃えた2.5本は、偶然の範囲（±4.2本）です。残りのレースは、相手の勝率が同じ層の一般戦が20レース未満で比べられません。

G1では、相手まで揃えても2.0本少ないまま、偶然の範囲の外に残りました。前の10年は、比べられたSGが354レースしかなく、選手の強さだけで揃えても差が出ていません（0.9本多い）。前の10年のG1は、相手まで揃えると不足が4.3本から4.8本に広がりました。

揃えた値で比べ直す

本文の数字は、SGと一般戦をそのまま比べた素の値です。同じくらいの強さの1号艇が一般戦で走ったときの値（物差し）と比べると、次のとおりです。物差しは、レースの種類、1号艇の級別と全国勝率、相手で一番勝率が高い選手との勝率の差を揃えた一般戦です。

勝率トップとビリの2着率の差は、物差しで33.5ポイント、SGで7.8ポイント。展示タイムは15.6ポイントと10.0ポイント、モーター2連率は2.1ポイントと6.1ポイントでした（2,879レース）。SGで、展示タイムと勝率の差は2.1ポイント、モーターと勝率の差は2.0ポイントで、どちらも偶然の範囲です。モーターがSGで物差しより大きく出たのはこの10年の2着だけで、前の10年もG1も偶然の範囲、3着では逆向きでした。

本文の2着の割合（24.5%など）は、揃えない素の値です。物差しの一般戦と比べ直すと、勝率が一番高い相手が2着に来たのはSG24.8%、物差し41.7%、一番低い相手はSG16.5%、物差し8.0%でした（2,879レース。この比べ方だけは、勝率が同じ相手を上の順番に数えています）。

物差しに「相手5人の勝率の散らばり」まで足すと、比べられたのは999レースです。

勝率が一番高い相手と一番低い相手の2着率の差は、SGで9.7ポイント。選手の強さだけで揃えた一般戦は33.6ポイントで、散らばりまで揃えると16.8ポイントになります。SGと一般戦の開きは23.9ポイントから7.1ポイントに縮み、残りは偶然の範囲（5.7ポイント）をわずかに超えました。前の10年は偶然の範囲の中でした（259レース）。

一番強い相手が何コースにいるかまで揃えても、勝率が一番高い相手と一番低い相手の2着率の差は、SG10.7ポイント、一般戦35.1ポイントのままでした（1,607レース）。

3連単の配当

1号艇がインから勝ったときの3連単の平均配当は、この10年、SGが2,521円、物差しの一般戦が2,046円で、23%高い（3,309レース）。単勝の差は3.7%なので、上乗せの多くはヒモの側です。

6艇の勝率がそろった2,880レースのうち、相手の勝率の散らばりまで同じ一般戦があるのは999レースだけです。その999レースでは、選手の強さだけで揃えた上乗せが17%、散らばりまで揃えると3%で、偶然の範囲に入りました。相手が一番揃ったSGは、この999レースから外れています。

決まり手で見ると

勝った艇のコースと決まり手で分けると、この10年のSGで物差しより一番増えていたのは、2コースの差しでした（1コースの艇の強さで揃えた4,746レース。100レースあたりSG7.1本、物差し4.8本で、差は2.3本）。ところが、2コースの選手の強さまで揃えて比べ直すと（3,511レース）、2コースの差しの増え方は0.5本で、偶然の範囲に入ります。

代わりに、どのコースからのものも合わせたまくり（1.9本）とまくり差し（2.7本）の増え方が、偶然の範囲の外に出ます。この比べ方（3,511レース）でも、インの1着は6.8本少ないままです。2コースの差しが目立って見えたのは、SGの2コースにも強い選手が乗っているからでした。

1枠の艇が1コース以外から出たのは、この10年のSGで0.74%、一般戦で1.35%です。

5年ごとの動き

物差しを5年ごとに作り直して比べると、4つの5年のうち3つで、SGのインは物差しを下回りました。5年ごとの値は、6艇の勝率がそろわないレースも含めて数えているので、本文の5.7本とは少しずれます。一般戦のインの1着率は、2006年の32.8%から55%前後まで上がっていて、物差しはその時期の一般戦だけで作っています。

1アタマの組と、細かい数字

2着を1人に決めて3着を流す1-X-全（4点）を、相手の勝率の順に分けて数えました。この10年のSGでは、勝率が一番高い相手を2着に置くと100円あたり80.2円、一番低い相手を置いても74.8円です。5つの順番の中で一番戻った組と一番戻らなかった組の差は、SG11.9円、物差しの一般戦20.5円でした。

過去20年に同じ組を毎レース同じ額で買っていた場合の記録です。図の5つの組のうち4つで、SGが物差しの一般戦より多く戻りました。どの組も、100円には届いていません。

この図、最初は1-56-56を入れずに作っていました。都合のいい組だけ並べた形になっていたので足すと、この10年は5つのうちこの組だけが、一般戦を25.3円下回りました。理由はまだ分かりません。

SGは開催場が偏っていて、1号艇が勝ったSGのうち6艇の勝率がそろった3,400レースで、447が住之江です。場まで揃えても、この10年は18%高く（764レース）、住之江を除くと24%高い（543レース）。住之江のレースだけでは5%高く（221レース）、偶然の範囲です。

物差しの一般戦が足りず比べられなかったSGのレースは、見たままのイン1着率が比べたレースより高く出ています。ただ、そのレースの物差しが無いので、本文の不足が大きめに出ているのか小さめに出ているのかは分かりません。

まだ数えていないもの

プロの言う展示は、周回展示での回り足や気配まで含みます。数えたのは展示タイムの順位だけです。モーター2連率は、使い始めて間もない時期の値をそのまま使っています。2連率が当てにならない時期の分だけ、モーターの絞れる幅は小さめに出ているかもしれません。

絞れる幅は、1番手と一番下の2点だけで見ています。展示タイムとモーター2連率で、2番手から4番手までが順番どおりに並ぶかは数えていません。

勝率の順番は、相手のいたコースごとに分けても数えました（本文）。ただし、物差しの一般戦で揃えたうえでコースまで分けることは、まだしていません。

ヒモの数字は、1号艇が勝ったレースだけで数えています。SGでは1号艇の1着が見込みより少ない分、勝てたレースは強い相手が崩れたレースに偏り、勝率の一番高い相手の2着率を下げているかもしれません。

当地勝率と、その節の成績（得点率）では並べていません。展示タイムより直前の気配を映すのは節の成績かもしれません。

SGに出る選手の全国勝率は、公式サイトの用語集によるとSGの着順点が各2点増しになる一方、強い相手と走るので、一般戦の選手の勝率と同じ目盛りではありません。どちらに偏っているかは、まだ確かめていません。

SGにしか残らない差の候補として、公式サイトのSG分析（2019年）は、予選の得点の仕組みから6号艇の選手が「2、3着で十分」と走ることを挙げています。元選手の解説者も、準優勝戦は得点上位が内枠に入るので内で決まりやすい、と話しています。どちらも、数えてはいません。

前付けの進入とスタートのタイミングは、20年分ではまだ分けていません。公式サイトの別のコラム（2014年）は、一般戦では1号艇に実力上位の選手を入れる「シード番組」が増えたこと、SG・G1は選手を1号艇から6号艇に均等に配ることを書いています。物差しが動いたのは、この違いのせいかもしれません。

売上と、選手ごとの人気の集まり方は数えていません。売上を数えれば、2着・3着の票の割れ方を確かめられるはずです。

  • 展示タイムとモーター2連率で並べた2着の順番、2着・3着の勝率の順番、相手の勝率の幅や散らばりまで揃えた2着の順番、一番強い相手のコースまで揃えた2着の順番、相手のいたコースごとの勝率トップとビリの2着率、2着のコース、1-X-全の戻り、勝った艇のコースと決まり手（2コースの選手の強さまで揃えた比べ直しを含む）、1枠の艇が1コースに入れなかった割合、レースの種類ごとのインと配当、相手まで揃えた比べ直し、相手の勝率で一番下と1番手、2着の順位、中央値、1号艇が勝ったときの配当、2点・6点・8点の組、5年ごとの物差しは、記事を書く途中で足した数え方です
  • 3つの数字、2着と3着、SGとG1、2つの10年と、たくさんの組み合わせを数えています。偶然の範囲の外に出たものが1つあっても、それだけで強い差とは言えません
  • 1号艇がインから勝ったSGで6艇の全国勝率がそろったのは、この10年3,400レース（2着が1人に決まったのは3,397）。物差しの一般戦が20レース以上あるのは2,880レース（同じく2,879）です
  • コースごとの勝率トップとビリの2着率は、1枠の艇が1コースから勝ち、6艇の全国勝率がそろったレースで、相手がいたコース（2から6）ごとに数え、5つの差を単純に平均しています。偶然の範囲は、開催日ごとに引き直す計算を200回して決めています
  • 差や倍率は、四捨五入する前の値で計算しています。図の値どうしで引くと、小数の最後の桁が合わないことがあります

  • 相手5人を全国勝率・展示タイム・モーター2連率で並べた2着の割合は、同じ値の相手がいるとき順番を等分して数えています（同じ値の2艇が1番手なら、どちらが2着でも1番手に0.5と数えます）。物差しで揃えた比べ直しの一部（折りたたみの24.8%など）だけは、同じ値の相手を上の順番に数えています
