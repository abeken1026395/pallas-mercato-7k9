勝負駆けは
効くのか

予選最終日、ボーダー付近の選手の走りは変わるのか。
約10年分・7,523節の予選最終日を数えた記録です。

「ここは勝負駆けですね」

予選の最終日、ボーダーのあたりにいる選手がピットを出ると、実況がそう言います。あと1走で準優に乗れるかどうかが決まる。気合いも入るだろう、と聞いている側も思う。

勝負駆けは、効くのでしょうか。

10年、7,523節

2016年11月1日から2026年8月31日まで、3,591日分の競走成績を1レースずつ並べ、同じ場で続いた開催日を節にまとめ直しました。準優のある節は7,523。予選最終日に走った選手を1人1日として数えると、325,535人日になる。

公式が得点率を出しているのは大きな開催だけなので、得点率は着順点から自分で計算しました。その得点率で準優の顔ぶれを当てると、延べ136,914人のうち127,704人が合っていて、93.3%。予選最終日の朝、誰がボーダーのどちら側にいたかも、同じ計算で決めた。

崖っぷちは、よく走っていた

ボーダーとの差が0.5点以内の選手を「崖っぷち」と呼ぶことにして、数える前に、比べ方を決めておきました。予選最終日の着順点を、同じ枠、同じくらいの強さの選手の平均と比べ、崖っぷちとそれ以外で差を取る。強さの物差しは、その選手の直前12か月の平均着順点。

崖っぷちの選手は、それ以外より0.13点よい着を取っていました。ラベルを1,000回入れ替えても、偶然でこの差に届いた回はない。

やはり効くのか、と思いました。

並べたら、坂だった

ところが、帯ごとに並べると、形が違います。

もう届かない（−2点より下）80,535−0.481.8%
圏外（−2から−0.5）77,985−0.1714.4%

やや圏内（+0.5から+2）64,140+0.2586.0%
安全圏（+2点より上）35,299+0.6195.4%

浮いているのは崖っぷちだけではなく、ボーダーの上にいる選手ほど、よい着を取っている。予選で上位にいる選手は、その節のモーターや調子がよかった選手でもあるので、最終日もそのまま走る。崖っぷちは坂の真ん中にいて、「それ以外」には坂の下の選手のほうが多く入っていた。先に決めた比べ方は、勝負駆けではなく、この坂を拾っていました。

比べ方を先に決めておいて、その比べ方に足をすくわれたことになります。

坂の上の段差

では、坂をならしたうえで、ボーダーのところにだけ段差があるのか。ボーダーからの差を0.25点刻みに並べ、崖っぷちの外側の形から、崖っぷちのところに来るはずの値を出して、実際と比べました。

段差は+0.04点。1着と2着の差の2点に比べると、およそ50分の1です。節を単位に1,000回組み直すと、見分けられる最小の差は0.03点で、それはわずかに超えている。

ほかの場所にも段差

ただ、ボーダーでない場所に同じ幅の窓を置いて同じ計算をすると、10か所のうち5か所で、これと同じくらいの段差が出ました。坂の曲がり方を式が拾いきれていない分と、見分けがつきません。年ごとでは、11年のうち10年で上向きでしたが、1年ずつでは、どの年も偶然の幅に収まる。

効いているとしても、枠ひとつぶんの20分の1。枠がひとつ内に入ると、予選最終日の着順点は平均で0.86点上がるので、勝負駆けの上乗せは、その端数にも届きません。

メイチなら、時計に出る

勝負駆けには、もうひとつ、よく聞く言い方があります。

「メイチの勝負駆け」

目一杯に攻めるなら、スタートに跡が残るはずで、同じコース、同じくらいの強さの選手と比べると、崖っぷちのスタートは実際に0.0023秒早かった。もっとも、スタートも坂の上にあって、坂をならすと段差は0.0007秒で、偶然と見分けがつかない。フライングの割合も、崖っぷちは0.41%で、圏外の0.46%とやや圏内の0.37%のあいだにいました。

スタートの記録は0.01秒刻みなので、0.0007秒はその目盛りの14分の1で、時計には、ほとんど何も残っていません。

現場は、坂の途中を見ている

最終日の崖っぷちがよく走って見えるのは、見間違いではありません。崖っぷちにいる選手は、圏外の選手よりその節の調子がよく、実際に平均より少しよい着を取っている。

現場で見えているのは、坂の途中にいる選手の走りです。こちらが数えたのは、坂からはみ出した分でした。坂の上の走りを気合いと呼べば、勝負駆けは効いて見える。坂からはみ出した分だけを数えると、ほとんど残らない。

決めていたのは枠

では、同じ崖っぷちで、進めるかどうかを分けていたものは何か。予選最終日の出走が1走だけだった崖っぷちの選手を、その日の枠で分けました。

1枠なら74.0%が準優に乗り、6枠なら28.9%。同じ崖っぷちでも、引いた枠で45.1ポイント違います。あいだの枠も、2枠52.1%、3枠48.0%、4枠43.5%、5枠35.1%と、外に行くほど段を下りるように下がっていく。予選最終日の枠は番組で決まるもので、選手が選べるものではありません。6枠を引いた崖っぷちで準優に乗れるのは、3人に1人に届かない。

ここから先は数えていない

反則による減点は、手元の競走成績から取れないので入れていません。開催の格も載っていませんが、同じ節の全員に同じだけ乗る加点なので、節の中の順位は変わらない。チルトの角度は2026年1月からしか手元になく、10年の比較には使えなかった。

外した選手もいる。予選最終日の前にフライングや妨害で順位から外れた6,378人日、準優のある節で予選最終日に走らなかった21,073人日は、比べていません。

気合いは、枠を埋めない

「ここは勝負駆けですね」は、嘘ではありません。崖っぷちの選手は、平均より少しよく走っている。ただ、それはその節の調子のぶんで、勝負駆けのぶんは、枠ひとつの20分の1ほどしか見つからなかった。

気合いは、45ポイントを埋めません。

この得点率について

この得点率は計算したものです。公式の実数ではありません。

公式が得点率を出しているのはG2以上の開催だけで、G3・一般では公開されていません。ここでは公式と同じ計算式で出しています。

計算のしかた

1着10点 / 2着8点 / 3着6点 / 4着4点 / 5着2点 / 6着1点。特選・選抜・ドリームなどの名前が付いたレースは1点を足しています。この合計を出走回数で割ります。
（出典：ボートレース公式 用語辞典）

実際とずれることがあります

公式には、待機行動違反などの反則で引かれる「減点」があります。着順には現れず、手元の競走成績からは取れないので、ここでは再現していません。

どれくらい合っているか

10年の準優のある 7,523節で、準優に乗った延べ 136,914人のうち 127,704人を言い当てました（93.3%）。

準優に乗れる人数は決まっていません

多くは18名で、10年の7,523節のうち6,591節（87.6%）。ほかに24名が552節、12名が358節ありました。

フライングをすると、順位そのものが付きません

フライングと妨害失格は「賞典除外」となり、順位から外れます。どれだけ着順が良くても、その節の準優には乗れません。

この検証の数え方
  • 期間：2016年11月1日から2026年8月31日。公式の競走成績（Kファイル）の3,591日分
  • 節：同じ場で続いた開催日をひとまとまりにし、優勝戦の日で区切っています。間が3日以上あいたら別の節です。準優のある節は7,523、準優のない節は7,892でした
  • 予選最終日の朝：準優の前日を予選最終日とし、その前日までの得点率で順位を付けています。ボーダーは、準優の定員の順位とその次の順位の得点率の中間です
  • 帯：ボーダーとの差が−2点より下を「もう届かない」、−2から−0.5を「圏外」、±0.5を「崖っぷち」、+0.5から+2を「やや圏内」、+2より上を「安全圏」としています
  • 着順点の差：予選最終日のレースごとに、同じ枠・同じ強さの段・同じ年の平均を引き、1日の中で平均しています。強さは、その選手の直前12か月の平均着順点を5段に分けたものです（30走に満たない選手は別の組）。着が付かなかったレースは入れていません
  • 先に決めた比べ方：崖っぷちとそれ以外の差を、強さの段と年の組の中で帯のラベルだけを1,000回入れ替えた分布と比べています（乱数の種は20260922）。理論上の確率分布は使っていません
  • 段差：ボーダーとの差が±0.5点の外側（±3点まで）の人日に2次式を当て、崖っぷちのところの予測と実際の差を取っています。偶然の幅は、節を単位に1,000回組み直したもので、見分けられる最小の差（偶然の揺れの2.8倍）は0.03点でした。ボーダー以外の10か所に同じ幅の窓を置いた比較も同じ方法です
  • スタート：同じ進入コース・同じ強さの段・同じ年の平均からの差で、フライングと出遅れは除いています
  • 枠と進出：崖っぷちで予選最終日の出走が1走だけだった選手に限っています。2走以上した44,446人日は、枠が1つに決まらないので入れていません
  • 比べなかった選手：予選最終日の前にフライングや妨害で順位から外れた6,378人日、予選最終日に走らなかった21,073人日、その前に1走もしていない343人日
  • 揃えていないもの：開催の格、反則による減点、チルト（2026年1月からしか手元にない）、モーターの良し悪し
  • 図：すべてこの検証の集計から描いたもので、外部の画像は使っていません
