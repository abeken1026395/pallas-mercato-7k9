この得点率について

この得点率は推定です。公式の実数ではありません。

公式が得点率を出しているのはG2以上の開催だけで、G3・一般では公開されていません。 ここでは公式と同じ計算式で出しています。

計算のしかた

1着10点 / 2着8点 / 3着6点 / 4着4点 / 5着2点 / 6着1点。
この合計から減点を引き、出走回数で割ります。
（出典：ボートレース公式 用語辞典）

実際とずれることがあります

公式には「減点」があります。待機行動違反などの反則で引かれる点で、 着順には現れないため、ここでは再現できません。
過去の実測では、選手のうち 5.3% にこの減点が入っていました。

どれくらい合っているか

過去 755節 の準優勝戦メンバーと照合しました。
準優に乗った延べ 13,632（実際の選手は 1,413名）のうち、 12,603 を言い当てました（92.5%）。

※ この数字は記事を書いた2026年8月の検証時点のものです。その後の毎日の答え合わせは、下の「再現率の推移」に足され続けています。

準優に乗れる人数は決まっていません

12名・18名・24名の3通りがあります。過去755節では18名が92%でした。

フライングをすると、得点率そのものが付きません

Fと妨害失格は「賞典除外」となり、順位から外れます。 どれだけ着順が良くても、その節の準優には乗れません。
なお転覆は減点されるとは限りません（選手の責任かどうかで変わります）。
