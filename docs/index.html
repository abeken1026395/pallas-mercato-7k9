      荒れる ＝ 3連単の払戻 5,000円以上

      朝に「荒れる」と分類した 20,176 レースのうち、荒れたのは 35.9%。全 66,404 レースでは 30.7%。「荒れる」と見なかった 46,228 レースだけなら 28.5%。

      荒れやすさを伝える見立てです。「荒れる」と見たレースの約3分の2は荒れていません。それも全部数えています。
