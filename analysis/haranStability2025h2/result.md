# morning7 係数の期間安定性（2025年後半での当てはめ）── 結果

検証日 2026-08-28。再現コードは `scripts/backtestHaran2025h2.py`（引数なしで実行・出力は標準出力だけ）。
このページは分析の記録であり、読者向けの公開ページではない。

## ★これは walk-forward の代わりにならない

`data/haranModel.json` の `morning7` は **2026-01-01〜2026-08-22 で引いた係数**である。
それを **2025-07-15〜2025-12-31 に当てた**＝時系列的に逆走している。

リークではない（2025年のレースは係数の学習に一切入っていない）が、**性能の証明にはならない。**
ここで言えるのは「**係数の向きと大きさが期間をまたいで保たれているか**」まで。
AUC が出たことを「安定」と読んではいけない。

## 結論

**向きは7特徴すべてで保たれている。大きさは2025年後半のほうが一段弱い。**

- 7特徴の単独AUCは全部が期待した向き（係数の符号と一致）で、rk1・last20・rkout・midLastBest は
  2026年とほぼ同じ。**符号が反転した特徴はひとつもない。**
- 合成スコアは 2026年 AUC 0.7128 に対し **2025年後半 0.6913（−0.022）**。
  上位10%の①着外率は 44.8% → **40.6%（−4.2pt）**。
- 10分位は2025年後半も単調に下がる（40.6 → 6.9%）。順位付けとしては壊れていない。
- **母集団の①着外率は 19.5%**。2026年の 18.9% より 0.6pt 高い（それ自体が発見）。

再学習が要るという結論には**ならない**。逆走の当てはめで下がるのは想定内であり、
再学習の判断材料は 2026-11下旬の実測（`data/haranModel.json` の注意書き）のまま。

## 食い違いの見立て（合わせにいっていない）

差は「2026年 0.7128 → 2025年後半 0.6913」。原因の候補を3つ挙げる。**どれも証明していない。**

### 1 助走がない（確実に効いている）

`results/` は **2025-07-15 から始まる**。窓の頭には過去走の蓄積がゼロで、
母数ガード（last20≥10・c1last10≥5・avgSt≥20・venOut≥200）に届かず欠損代替値で埋まる。

- 2025年後半で **7特徴が全部そろった行は 68.3%**（1レース平均 0.90特徴が欠損）
- 2026年は **99.3%**（同 0.01）

助走の薄い7〜8月を落として **2025-09-01〜12-31** で測り直すと AUC 0.6946・上位10% 41.5%。
**そろい率は 92.1% まで上がるのに、差は 0.022 → 0.018 しか縮まらない。**

さらに **7特徴が全部そろった行だけ**に絞ると：

|範囲|n|母集団|AUC|上位10%|下位10%|
|---|---|---|---|---|---|
|2025後半 全行|24,903|19.5%|0.6913|40.6%|6.9%|
|2025後半 欠損ゼロ|17,008|17.4%|0.6860|37.5%|6.8%|
|2026年 全行|30,971|18.8%|0.7128|44.8%|5.8%|
|2026年 欠損ゼロ|30,763|18.7%|0.7117|44.3%|5.8%|

★この行は**そのままでは比較できない**。2025年の「欠損ゼロ」は
**過去走が十分ある選手＝出走数の多い選手**に偏った部分集合で、母集団の①着外率が 17.4% と
2.1pt 低い（＝①が強い側に選ばれている）。倍率で見ると 37.5/17.4=2.16倍 対 44.3/18.7=2.37倍。

**→ 欠損だけでは差を説明しきれない。**

### 2 `c1last10` と `avgSt` の推定が薄い（likely）

この2つだけ単独AUCが落ちている（−0.031 / −0.026）。どちらも**蓄積が要る特徴**で、
2025年後半は本数が足りない・欠損率が高い（30.1% / 20.8%）。
値そのものの分布は2026年と変わらないので、**特徴の性質が変わったのではなく推定が粗い**という見立て。

### 3 `venOut` の散らばりが大きかった（小さい）

場の①着外率は 2025年後半 平均20.08%・sd 4.08 に対し 2026年 19.16%・sd 3.45。
平均のずれ（+0.65）は全レースに同じ量が乗るだけなので**順位付けには効かない**が、
散らばりが2026年より14%大きいぶん、`venOut` が設計より強く効いている。係数 +0.18006 と
軽い特徴なので、寄与は小さい。

### 母集団の①着外率が 19.5%（2026年 18.9%）

**2025年後半は①が実際に飛んでいた。**月別では7月 21.5% が最も高く、11月 17.8% が最も低い。
①が飛びやすい期間なら上位10%も上がりそうなものだが、逆に下がっている。
**「荒れた」ことと「荒れを当てられる」ことは別物**という読み方をしている。
